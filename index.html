🔒 Before you begin — where your data goes

This is a personal tool. Your coaching sessions contain vulnerable, private thoughts. Here's exactly what happens with them:

📱 Your browser

All conversations, settings, and your API key are stored in this browser's localStorage. They never leave your device unless you trigger an API call or Sheets sync. Anyone with physical access to this browser can inspect localStorage and see everything.

🔗 OpenAI's servers

When you start a session, your text is sent over HTTPS to OpenAI's API for processing. OpenAI retains API inputs and outputs for up to 30 days for abuse monitoring. During that window, a limited number of authorized OpenAI employees and contractors can access data to investigate suspected abuse. After 30 days, it's deleted.

API data is not used for model training unless you explicitly opt in (you haven't). If you share an API key with friends, nobody — not you, not your friends, not OpenAI's dashboard — can see the content of each other's sessions. The key is only for authentication and billing.

📊 Google Sheets (optional)

If you configure it, a copy of each exchange is sent to your Google Sheet via a webhook. That data lives in your Google Drive and is only accessible to you (unless you share the sheet).

⚠️ This is not therapy

This tool draws from cognitive coaching frameworks for everyday thought patterns, goal-setting, and self-awareness. It does not replace professional mental health support. If you're in crisis, please reach out to a qualified professional.
